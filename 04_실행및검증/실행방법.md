# 04 실행 및 검증

## 요구 환경

- Java 17 이상
- 별도 Maven 설치 불필요 (`mvnw.cmd` 포함)

## 실행

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21'
.\mvnw.cmd spring-boot:run
```

기본 포트는 `8080`, H2 콘솔은 `/h2-console`, 상태 확인은 `/actuator/health`입니다. DB 파일은 실행 위치의 `data/`에 생성됩니다.

## 테스트

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21'
.\mvnw.cmd test
```

## 환경변수

- `SERVER_PORT`: 서버 포트
- `CORS_ALLOWED_ORIGINS`: 쉼표로 구분한 허용 프런트 주소

## 검증 기준

- 풍력 밀도: `0.5 × 1.225 × v³`
- 회수 전력: `밀도 × 면적 × 효율 × 배치계수`
- 배치계수: `exp(-0.13 × (거리-1)) × cos²(각도)`
- 연 발전량: `전력 × 일 운전시간 × 연 운전일 ÷ 1,000`
- 절감액/탄소량/단순 회수기간이 기존 프런트 식과 동일해야 합니다.
