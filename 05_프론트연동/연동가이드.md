# 05 프런트 연동

기존 `dist/app.js`의 `buildings` 배열과 `calculation()` 함수가 백엔드로 이동했습니다. Three.js 장면과 UI 상태는 그대로 프런트에 둡니다.

## 시작 시 건물 목록

```js
const API = 'http://localhost:8080/api/v1';
const buildings = await fetch(`${API}/buildings`).then(check).then(r => r.json());
```

건물 진입 시 `GET /buildings/{id}`를 호출해 `hourlySeries`를 그래프와 시간 슬라이더에 연결합니다.

## 계산

```js
const result = await fetch(`${API}/simulations`, {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    buildingId: selected.id,
    sourceMode: manualSpeed ? 'DIRECT_SPEED' : 'TIME_SLOT',
    hour: manualSpeed ? null : Number(hour.value),
    windSpeedMS: manualSpeed ? Number(speed.value) : null,
    collectionAreaM2: settings.area,
    efficiencyPercent: settings.efficiency,
    distanceM: Number(distance.value),
    angleDegrees: Number(angle.value),
    operatingHoursPerDay: settings.hours,
    operatingDaysPerYear: settings.days,
    tariffKrwPerKwh: settings.tariff,
    carbonFactorKgPerKwh: settings.carbon,
    installationCostKrw: settings.cost
  })
}).then(check).then(r => r.json());

function check(response) {
  if (!response.ok) throw response;
  return response;
}
```

슬라이더를 움직일 때마다 호출하면 요청이 많아지므로 150~250ms debounce를 적용합니다. 기준안 버튼은 당시 요청 객체를 브라우저에 보관하고 `/simulations/compare`의 `baseline`, `current`로 전송하면 됩니다.
